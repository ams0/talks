# Life of a token

Redesigned HTML presentation for Game of Codes 2026, Niš.

Open `index.html` in a modern browser. Keep the accompanying files in this folder. No build step or internet connection is needed to present. A self-contained HTML edition is also supplied separately.

## Presenting

- Right arrow / Space: next reveal or slide
- Left arrow: previous reveal or slide
- Up / Down: previous / next slide, bypassing reveals
- Home / End: first / last slide
- N: speaker notes
- T: start / stop the 27-minute timer
- F: fullscreen
- P: print (enable background graphics in the print dialog)
- URL `#12`: open slide 12 directly

Use `SCRIPT.md` for timing, optional cuts, explanations and numerical assumptions. Configuration snippets illustrate the architecture; they are not deployment-ready manifests. Hardware and capacity calculations are illustrative rather than benchmark results.

## Editing

Slide content, CSS and presentation controls are in `index.html`. Technical graphics remain editable inline SVG. `fonts.css` and `fonts/` bundle the fonts for offline use; their OFL licenses are included. `token-hero.png` is an AI-generated conceptual illustration used as a background. The author portrait and event mark come from the original presentation.
